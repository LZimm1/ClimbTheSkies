## Table of Contents

2. [Controls](#controls)

## Installation

1. Clone the repository:
```bash
   git clone https://github.com/LZimm1/ClimbTheSkies.git
```
2. Open the project in Unity Hub.
3. Press **Play** in the Unity Editor to start the game.

## Controls

- **Arrow Keys** or **WASD**: Move
- **Spacebar**: Jump
- **R**: Restart
